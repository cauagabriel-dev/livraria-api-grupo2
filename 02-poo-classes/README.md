# 02 — POO: classes, métodos e encapsulamento

## O que foi feito
Criação das classes `Livro` e `Categoria`, primeiras entidades do domínio da API da Livraria, com atributos, métodos

## O que eu aprendi
- A classe é o molde e o objeto é feito a partir dela com `new`
- `this` se refere ao objeto que está sendo usado naquele momento
- Atributos com `#` ficam privados e só são acessados por dentro da classe
- `get` permite ler e `set` permite escrever com validação

## Como executar
```bash
node testar.js
```
